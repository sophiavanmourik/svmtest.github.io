# Sophia portfolio site

Upload the CONTENTS of this folder to the root of `sophiavanmourik.github.io`.

## Structure
- index.html
- css/style.css
- js/network.js
- images/*

All bundled images are placeholders. Replace them with your own files while keeping the exact filenames, or update the `src` paths in index.html.

After uploading, hard refresh with Ctrl+Shift+R.
